# ProjectHub

ProjectHub is a Project Management Web Application built using React, Node.js, Express.js and MySQL.

## Features

- User Registration & Login
- Create Projects
- Delete Projects
- Search Projects
- Create Tasks
- Update Task Status
- Delete Tasks
- Progress Tracking
- Due Date Management
- Dashboard Analytics

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js

Database:
- MySQL

# ProjectHub 📋

A full-stack Project Management Web Application built using React.js, Node.js, Express.js, and MySQL. ProjectHub helps users manage projects, organize tasks, track progress, and improve productivity through an intuitive dashboard.

## Features

* User Registration & Login
* Create Projects
* Delete Projects
* Search Projects
* Create Tasks
* Update Task Status
* Delete Tasks
* Project Progress Tracking
* Dashboard Analytics
* Due Date Management
* Responsive UI

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js

### Database

* MySQL

## Installation

### Clone Repository

```bash
git clone https://github.com/NIdhiSingh162/ProjectHub.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```
